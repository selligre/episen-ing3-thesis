\begin{posterbox}[name=problem, span=2, column=0, row=0]{Problem}
	Kernel-level anti-cheats (Ring 0) are becoming the industry standard for stopping cheaters in competitive FPS games such as Counter-Strike 2, but they require granting a driver unrestricted access to the entire system, not just the game. This creates three risks:
	\begin{itemize}
		\item \textbf{Security}: expands the attack surface
		\item \textbf{Privacy}: violates GDPR principles of minimization data access
		\item \textbf{Trust}: drives boycotts, excludes Linux users
	\end{itemize}
	This thesis explores an alternative: detecting cheaters through server-side behavioral analysis of gameplay telemetry, without ever touching the player's machine.
\end{posterbox}

\begin{posterbox}[name=rings, span=1, column=2, row=0]{Privilege Rings}

	\smaller Kernel-level anti-cheats and kernel-level cheats compete for the same Ring~0 authority, leaving no visibility to user-mode software.
\end{posterbox}

\begin{posterbox}[name=flags, span=1, column=0, below=problem]{Detection Flags}
	\begin{center}
		\includegraphics[width=\linewidth]{../images/chap03/flag_frequency.png}
	\end{center}
	\smaller Five of the eight flags fire in over 90\% of cheater sessions but stay silent on skilled players — except HS\_RATE\_EXTREME, which also fires for 83\% of skilled sessions, exposing it as the weakest, least discriminative signal on its own. Cross-session persistence across \emph{several} flags, not any single flag, is what separates cheaters from skilled players~\cite{Loo2025}.
\end{posterbox}

\begin{posterbox}[name=risks, column=1, below=problem]{Kernel-Level Risks}
	\smaller
	\begin{itemize}
		\item Structural arms race: cheat vendors patch around detections faster than publishers can ship kernel updates
		\item Categorical blind spot against DMA (hardware) cheats: no software footprint on the host at all
		\item \textbf{Experiment}: using Windows-Kernel-Explorer and Cheat Engine on an isolated VM, a plaintext string was located and reconstructed from an \emph{unrelated} Notepad process's memory
		\item Confirms that Ring~0 access is not just theoretically broad, but trivially exercisable against any resident process — browsers, password managers included
	\end{itemize}
\end{posterbox}

\begin{posterbox}[name=suspicion, span=1, column=2, below=rings]{Suspicion Score}
	Each player session is scored by two independent layers combined into a single suspicion score:
	\begin{equation*}
		\text{score} = 0.6 \times \text{heuristic} + 0.4 \times (100 \times \text{lstm\_prob})
	\end{equation*}
	The heuristic layer evaluates 8 weighted, threshold-calibrated flags (time-to-damage, pre-aim, spray control, reaction time, \ldots); the LSTM layer models round-by-round behavioral persistence. A flag only counts if it recurs across a player's match history, not a single session.
\end{posterbox}

\begin{posterbox}[name=results, span=2, column=0, below=flags]{Results}
	\smaller
	\textbf{Zero false positives}: no legitimate player is ever misclassified as a cheater.

	\begin{center}
		\includegraphics[width=0.9\linewidth]{../images/chap03/confusion_matrix.png}
	\end{center}

	Kernel-level and server-side detection fail on opposite classes of cheat (one blind to hardware-level manipulation, the other blind to a cheat used once and never again), making them complementary layers rather than substitutes~\cite{Dorner2024, Collins2024}.
\end{posterbox}
